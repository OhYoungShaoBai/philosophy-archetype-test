# Roadmap

## v0.2.7 - Match strength and mixed profile presentation

- Use five philosophy domains: epistemology, ontology, ethics, political/social philosophy, and life/meaning philosophy.
- Make thought experiments the primary measurement surface, with twenty costed choice steps across four integrated scenarios.
- Put all five domains inside every scenario so each domain is tested across multiple kinds of situation.
- Show each experiment option's upside before selection, then reveal only the selected option's cost after the user commits.
- Keep ten low-cue calibration items and combine them with experiment choices at an 80/20 weight; use five-point checks for axis domains and ranking checks for multi-tradition domains.
- Represent epistemology and life/meaning as axes; represent ontology, ethics, and politics as multi-tradition distributions.
- Present five-domain profiles, hand-written archetypes, ideology/school labels, and thought experiment path replay.
- Present archetype closeness as match strength instead of a raw percentage, with mixed profiles treated as a normal philosophical result.
- Keep raw distance-derived scores internal for sorting and testing rather than normalizing them into an exam-like 100-point grade.
- Use internal representativeness checks for coverage, reachability, and simulated concentration without claiming population-level validation.
- Keep the project framed as a philosophical self-understanding tool, not a validated psychometric instrument.

## v0.3.0 - Expanded result experience

- Add a polished share card layout for each result.
- Improve copy text for social sharing and personal notes.
- Support saved portrait result images.
- Replace reused result illustrations with fifteen archetype-specific images.
- Expand result interpretation with internal philosopher, school, and reading cards.
- Add archetype-first portrait content so results explain judgment style, action pattern, relationship habits, and growth edges before introducing philosophy resources.
- Recalibrate question wording around philosophical reasons rather than generic good answers, and cover broader classic problem families across all five domains.
- Keep the expanded result experience in-page without public result URLs or external links.

## v0.4.0 - Public-ready release

- Prepare deployment options.
- Add project intro and measurement disclaimer copy.
- Run broader browser and mobile checks before public sharing.

## v1.0.0 - First stable release

- Freeze the first public question/result set.
- Publish a stable URL.
- Keep future changes tracked through tagged releases.
